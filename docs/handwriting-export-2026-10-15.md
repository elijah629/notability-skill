## Natural variation is unresolved

The repeated-letter diagnostic at `output/images/m027-repeated-letters.png` uses the actual current m027 neural decoder: rows `a/b/e/g/k/q`, six occurrences each, seed 419, variations 0, 0.5 and 1. No external jitter, source-trajectory lookup, font substitution or retraining was added. All panels use the same scale and the same 0.025-em pen.

At variation 0, repeated shapes are identical. Variation 0.5 introduces differences but also visible stem wobble, especially in `b`. Variation 1 produces jagged and distorted `a/b/e/g`, sometimes changing recognizable identity. The owner judged these differences unnatural. **Different coordinates do not establish natural handwriting variation.** m027 has improved fixed-mean legibility, but nonzero variation has not passed naturalness or identity-preservation review.

Raw output-scale coordinate RMSE between repeated occurrences ranges from 0.00950 to 0.07148 em at variation 0.5 and from 0.02709 to 0.29107 em at variation 1; it is zero at variation 0. These measurements establish variation magnitude, not quality. Private receipts are under `reports/legibility-v19/repeated-letter-demo/`.

Controlled demos continue to use **`--seed 419 --variation 0`**. The exported skill now recommends these explicit flags in both Nix and direct-binary commands, and identifies nonzero variation as experimental with possible jagged/jittery letters. The runtime's argument defaults were not changed. Future training must separately improve natural shape variation while preserving letter identity, corners and smooth pen motion; more training alone has not been shown to solve this.

## Lossless packaging change

The Rust exporter now compacts decoder JSON by removing only JSON whitespace outside quoted strings. It preserves **every numeric token, string, escape, neural layer and weight**, including the embedded frozen reference head. It performs no rounding, quantization, pruning or source-model mutation. It retains the standalone inference binary, pinned Nix runtime definition, vocabulary, manifest, dependency licenses and checksums. It counts every archived file, including `checksums.json`, and rejects exports at or above 25,000,000 uncompressed bytes before creating the ZIP.

Whitespace changes the file hash, so export provenance distinguishes:

- Source/current model decoder: `cac8182d095b4e4bd76d57b8c32f59e5700c64f484f19f6345d5846c283701cc`.
- Compact exported decoder: `6bccb239ebefcd7202a041101b3255bc1fdbdd556e134574078b98db7634cb5e`.

The export manifest sets `decoder_sha256` to the compact file and records `export_source_decoder_sha256` plus `export_decoder_format`. The repository model is untouched. Generated ink JSON correctly identifies the compact decoder when run from the skill.
