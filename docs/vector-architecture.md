# Neural vector architecture

Current source uses experimental `sequence-cvae-v14`; see [the model repair](model-repair-2026-10-18.md). A separate GRU-128 reads previous native ink, full-text context, style and log token count, then predicts three positive-increment Gaussian windows in token units. Their cumulative centers replace a fixed linear event/text clock. Both recurrent local text and output attention use these learned windows. Complete-row end coverage supplies weak alignment supervision; no character boundaries are annotated or inferred into accepted data. Teacher forcing runs fused GRUs; native scheduled recurrence and pure Rust export share the same window protocol. Long-path parity covers 64/400 cubic segments with unequal text and event padding. Wide accumulation and compensated Rust sums prevent cumulative window drift. Historical decoders retain fixed-clock and 155/284-input semantics.

The first 10,000 updates use canonical zero-style teacher forcing. Alternate scheduled batches then ramp self-fed probability over 20,000 further updates; learned-duration feedback begins at full probability. KL begins after canonical warmup. v13 reversible normalization divides by the maximum of source height, source width/supplied token count, original pen diameter and epsilon. This keeps repeated text from shrinking individual pen motions; every original cubic control, event and width round-trips. v14 separates pen-lift position errors (source-height units, smooth L1 beta 0.02, equal weight for every native MOVE) from curve displacement/width errors (native events/token density-scaled units, beta 0.1, native stroke weights). Present MOVE/CURVE classes receive equal objective mass. Dense curves therefore cannot dilute a sparse pen-lift location, and additional controls still demand proportionally finer curve precision. Complete-path geometry uses masked smooth L1 in source-height units (bounded scale/height gain 1–32), alongside native cubic likelihood, per-event geometry and curvature supervision. Previously a tenfold wider sample reduced the same physical path penalty by 100 times. Source arrays, event count, pen lifts, controls and widths remain unchanged. Historical nine-label curricula pass; full-data readability, joining and personal fidelity remain separate unresolved gates. Historical compositional v20 and old inference conventions remain loadable; changed recipes require transfer and fresh optimizers.

Training execution is recorded separately from the architecture recipe. New GPU models use length buckets of at most 64 rows and 16,384 padded events, with no row truncation; CPU uses at most eight rows. Every checkpoint records `execution_plan` and its actual `batches_per_epoch`. Resume preserves those exact boundaries for matching recipes; historical eight-row plans remain readable, while v4 resume is now blocked by the normalization change. Immutable padded GPU inputs may be cached up to 256 MiB. Text conditioning is shared between reconstruction and duration losses rather than recomputed. Precision and the exported network stay unchanged. The wrapper uses release builds. See [throughput measurements and limits](training-throughput-2026-10-16.md).

Skill exports compact decoder JSON by removing only whitespace outside strings, retaining exact numeric tokens and all weights. Export manifests distinguish source and compact decoder hashes. The archive includes licenses/checksums and must remain below 25,000,000 total uncompressed bytes. Skill examples explicitly use seed 419/variation 0; nonzero variation remains experimental and visually fails naturalness for m027. See [the export receipt](handwriting-export-2026-10-15.md).

`ink-corpus` imports the immutable ZIP and audits original cubic controls, widths, stroke order, lineage and supplied source-grouped splits. Sequence encoding uses reversible, sample-level isotropic normalization and relative MOVE/CURVE/EOS events. v5 scales by the maximum of control-bounds extent, original pen diameter and epsilon; historical evaluation retains its original control-bounds normalization. Every train sample is eligible; there is no atomic-only or eight-stroke filter in the sequence branch. Original source arrays are never rewritten.

`ink-layout` owns a bounded LaTeX AST and semantic tokenizer shared by training and inference. It supports grouping, scripts, fractions, indexed roots, boxes/enclosures, accents, phantom space, stretch delimiters, matrix families, cases, aligned/gathered/array layouts, text and spacing. Glyph metrics distinguish cap height, x-height, descenders and punctuation. SVG bounds include generated controls, structural paths and pen thickness.

Generated drawings use one output-space pen width, 0.025 em. Original widths remain unchanged in source data and previews. Every written character, including multiplication dots, punctuation and stretch/matrix delimiters, now uses its own learned condition. Donor-symbol substitutions and procedural character construction are retired. Historical glyph layout still composes fractions, roots and enclosures with explicit layout rules; the new whole-sequence path decodes every mark jointly and emits no procedural paths.

`ink-model` trains a sequence CVAE with 48-dimensional token embeddings, GRU-128 text/posterior/decoder networks, 16 style dimensions, masked cross-attention and five Gaussian components over cubic deltas and width. Original geometry is preserved without augmentation or teacher-input zeroing. After canonical warmup, zero latent, normal-prior and posterior training occupy one quarter, one quarter and one half of updates. Direct geometry scaling accounts for native event density without resampling or inferred segmentation. Historical v20 excludes ordinary connected words from its disjoint glyph loss and prevents mixed Greek/T practice from supplying strong Latin T evidence; current recipes skip that auxiliary.

`ink-neural` executes exported weights in pure Rust without source-ink lookup. New decoders carry `whole_run: true` and jointly generate the complete expression with one isotropic placement transform. Original joins, pen lifts, delayed crossbars, relative spacing and baseline movement can survive without character segmentation. Mixture means and shared document/run style latents replace independent coordinate noise. Historical decoders default to the older glyph path; these code changes do not certify their naturalness. `run_labels` accounts for requested content without implying letter-to-stroke alignment.

Models retain checkpoint weights, Adam moments, source/data/Nix hashes, vocabulary, recipes, full train lineage, auxiliary lineage and evaluation. Batch order derives deterministically from update/epoch; random augmentation derives from update count. Checkpoints are periodic, and a time budget replaces the sequence update cap. Resume rejects incompatible data, recipes, vocabulary or checkpoint hashes. New model IDs are allocated automatically; old v2 models remain selectable.

Explicit `train --model ID` without `--resume` selects a compatible network parent and allocates a new version with fresh optimizers. Recipe/corpus changes are permitted only through this transfer path; checkpoint and lineage hashes are verified, current holdouts cannot occur in parent training sources, and embeddings map by exact token. Automatic parent selection remains restricted to exact recipe/corpus/vocabulary matches. Resume remains exact. Separate public and personal corpus stages are enforced; public writers cannot cross splits, public rows require provenance/license metadata, and public output is identified as `neural-run-public`.

Head recipes v16/v17 separate eight learned topology modes per condition instead of averaging different pen-lift patterns into the same prefix slots. v16's global monotonic alignment failed because real source rows contain delayed/cross-cell strokes; it is retained as an experiment in versioned recipes and archived under `legacy/model-experiments/v16/`. v17 uses transient whole-row spatial attention, retaining original stroke order within each inferred cell and rejecting empty/overwide ambiguous assignments. Canonical shape/aspect reconstruction follows this internal correspondence; no character sample dataset or accepted character annotation is created. Uncertain and connected rows retain weak whole-row supervision, and all original rows remain in the sequence objective. Source-relative straight-path and curvature losses constrain learned geometry without substituting font or exemplar paths. Zero-latent reconstruction is explicitly trained alongside bounded latent variation.

Runtime selects one learned mode using distinct train-source support, with no coordinate averaging across modes and no source lookup. Legacy one-mode decoders retain identical behavior. Private mode-support state is hash-checked in `glyph-topology-evidence.json` for recovery; only its hash enters the manifest. Exports contain learned biases, per-mode advances and preferred mode indices, excluding private support records and source trajectories.

Recipe v18 protects canonical supervision from uncertain ordinary-word alignment: supplied singleton/separated practice anchors supervise their existing conditions, while short complete contexts supply missing conditions only. All complete rows still participate in weak auxiliary or full sequence objectives. Recorded ambiguous singleton `0/9` forms remain weak supervision. Near-closed source paths add a closure penalty on learned endpoints, preserving loops without procedural letter substitution. Mode grids support generated-output review independently of source annotation acceptance.

Recipe v19 matches source-relative second differences rather than minimizing curvature itself, preserving authentic sharp corners. `model glyphs` renders fixed-seed, zero-variation mode grids with source-support counts and an optional trained reference model. Hash-pinned selections may choose supported learned modes or embed the frozen reference head for selected conditions. Normal inference reads only the resulting decoder; it never loads another model directory or source ink. Calibration validates all choices before writes, preserves a recoverable pre-calibration copy, rejects approved models/stale reviews, and records reference/selection hashes. Checkpoint snapshots remove inference-calibration claims because optimizer checkpoints predate those selections.

Visual mode selection may also choose a condition's weakly supervised mode after verifying its hash-pinned complete train-row lineage; the manifest records these choices separately. They do not become accepted character annotations. Structural glyph composition explicitly records its neural donor in `condition_label`: semicolon uses comma plus a point; accented Latin letters reuse their learned bases plus procedural cubic marks; inverted question/down arrow rotate existing neural geometry. Membership and proportionality reuse compatible learned epsilon/alpha shapes. All carry `neural-composed-symbol` provenance and the constant document pen. See the [final m027 receipt](handwriting-m027-2026-10-15.md) for the exact selection and limits.

Validation may guide development; test remains separate from weight updates. Evaluation separates teacher-forced posterior/prior geometry, event accuracy, duration and latent statistics from free-generation readability. Full verification records every dataset request, exact-seed reproducibility, termination, glyph-request coverage, finite bounds and provenance. A recorded visual review and matching full-generation decoder/dataset hashes are required before setting `approved_for_default`; approved weights are retained in immutable inference snapshots. a successful train or low loss is insufficient.

`ink-infer` and the exported skill contain only inference code, weights, vocabulary, manifest and licenses. Neither Torch, Python, an encoder, optimizer nor source trajectories are shipped. Optional offline ONNX diagnostics remain separate.
