# Engine configuration

These files configure the active training graph and retained checkpoint compatibility tests. They contain no learned weights or handwriting samples.

`sequence-cvae-v14.json` and `compositional-vector-v20.json` describe the current experimental training objectives. `glyph-cvae-v2.json` supports the original atomic trainer. The two v10 files cover older checkpoint compatibility and regression fixtures.

Historical recipe revisions and visual mode selections stay in the owner's ignored `.private/research/recipes/`. The public download is one skill ZIP, not a collection of model experiments.
